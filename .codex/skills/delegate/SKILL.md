# Assigned Wildfire Work

Use for an assigned GitHub issue or a bounded subtask of an authorized request.

Read `AGENTS.md`, the assignment, and the relevant code/evidence. If an issue is assigned, read it and consult `kanban/github-issue-workflow.md` for issue operations. A role guide under `kanban/roles/` can help when its concerns apply; it does not replace judgment.

Verify branch/worktree and write ownership before editing. Preserve unrelated changes, coordinate overlapping files, and keep useful work moving within scope. Send findings that materially change the plan to the coordinator promptly.

Commit coherent progress and run checks that exercise the changed behavior. Update compressed `CONTEXT.md` state for handoff. Report commits, behavior changes, checks/results, and remaining risks; the assignment determines who posts durable issue updates. Report process friction only when it warrants action.
