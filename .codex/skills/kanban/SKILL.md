# Coordinate Wildfire Work

Use for backlog selection, issue coordination, or an explicitly requested issue sweep in `~/repos/wildfire`.

Read `AGENTS.md`, `kanban/github-issue-workflow.md`, and the relevant issues. Consult `docs/INDEX.md` to find task-specific design and validation references; do not read every project document by default.

Agree on the scope and completion condition. Delegate substantial independent work when useful, then continue local investigation, implementation, or integration in an unclaimed scope. Use `kanban/assignment-packet-template.md` for ownership handoffs and `kanban/roles/coordinator.md` for coordination considerations.

Keep GitHub updates and integration under a named owner, and route all shared Timberborn actions through one live controller. Save progress in coherent commits and compressed `CONTEXT.md` state. Report completed work, actual verification, and remaining blockers when the agreed scope is complete or the user pauses it.

Role guides are optional lenses. There is no mandatory role sequence, separate process review, or issue creation step for work already authorized by the user.
