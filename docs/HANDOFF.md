# Wildfire Work Handoff

Start from the [documentation index](INDEX.md), [source map](source-map.md), and [GitHub Issues](https://github.com/Ustice/Timberborn-Wildfire/issues). GitHub owns active backlog and acceptance state.

Keep an active task's branch, worktree, decisions, evidence pointers, and next action in its ignored `CONTEXT.md`. At closeout, put durable results in the issue, PR, or a dated report. This file does not track a shared machine's running game, stale blockers, or the next assigned ticket.

The [2026-09-04 archive](history/2026-09-04/HANDOFF.md) preserves the previous handoff, including its May 2026 construction-state crash evidence. Those warnings describe that run and its touched saves; they do not establish the state of today's process or every save.
