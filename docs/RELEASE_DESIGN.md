# Release Design

[DESIGN.md](DESIGN.md) describes the implemented data model and gameplay boundaries. Release scope and remaining acceptance work live in [GitHub Issues](https://github.com/Ustice/Timberborn-Wildfire/issues); versioned release notes belong in the changelog. There is no independent branch-relative behavior specification in this file.

Use [validation](TEST_PLAN.md), [versioning](release/versioning.md), and [Workshop packaging](release/workshop.md) for release preparation. Support and readiness require evidence from the actual packaged artifact in its target game environment.

The [previous release design](history/2026-09-04/RELEASE_DESIGN.md) retains the earlier tuning rationale and gameplay descriptions. It compared an unspecified working branch with `main` and contains superseded formats, including the old ash range. Use it as a design record, not a current release claim.
