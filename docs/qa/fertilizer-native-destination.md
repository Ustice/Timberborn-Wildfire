## Implemented contract

A tree target retains the exact initialized `TreeRemoveYieldStrategy.Reacher.Destination`, which must be a native `PositionDestination` on the same live entity. Missing, foreign or replaced role/destination evidence rejects admission or continued use. Original plant placement and its `CoordinatesAtBaseZ` soil cell remain separate from the worker endpoint. Non-tree targets and existing Warden/Ash/Borrowed Vector3 callers retain their existing native launch route.

The shared driver launches `Walker.GoTo(IDestination)` without cutting, reserving yield, invoking `NotifyReservableReached`, moving a model or wrapping the serializable destination. Candidate preflight uses the destination's actual path. It remains advisory: native Walker owns path-start/district handling, and the installed-path event checks its complete resulting path from actual Transform position. Indoor candidate starts can conservatively decline; this code does not reproduce the private path-start engine.

`StartedNewPath` occurs **before** native `FindPath` publishes its current destination. During that event the helper records the installed endpoint as unverified, checks fire safety and may pause. It never stops inside that callback. After the native call returns it requires exactly one start and reference-identical native destination. The existing fingerprinted `TimberbornOwnedWalker` seam reads the exact `_currentDestination` field; native value equality is insufficient.

Natural native arrival clears that pointer. Arrival then requires previously verified destination evidence, the unchanged actual installed endpoint, reachable/stopped state, current actor-position safety and native `INavigationService.InStoppingProximity` at that endpoint. The existing soil/application-cell safety remains separately checked. Deliberate Stop before Ready retains this evidence because native Walker preserves its installed corners. Ready loss of arrival settles the finite attempt; consumption and phase publication recheck arrival along with existing actor/job ownership.

An unsolicited same-reference refresh pauses and is revalidated after return. A foreign reference, even value-equal, cannot supply a new arrival. An unsolicited immediate success with an already-null pointer is conservatively rejected. Nested starts reject; stop remains after native return. A path event in the ignored Ready phase invalidates this job's evidence without touching the foreign mover. Arbitrary code using the very same native destination instance is indistinguishable from native Refresh; this is not general navigation mutation isolation.
