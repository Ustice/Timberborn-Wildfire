# Conditional clean ash collection

This protocol provides a receipt for actual simulator-owned removal. The [native ash-worker prototype](../qa/ash-native-harvest-prototype.md) now uses it for one-unit collection and guarded native deposit; live worker/save validation remains outstanding.

`IFireSimAshCollectionSimulator.TryCollectAsh(FireSimAshCollectionInput, Action<FireSimAshCollectionReceipt>)` admits one exclusive input after the next ordinary queued batch. Full capacity returns null without ticking or enqueuing collection. Invalid cell/request arguments fail before admission. `Requested` is explicitly 0–3; zero is a valid request with a GPU-authored zero receipt. Generic `RegisterChange` and `TryTickWithInput` reject any collection field, including zero. The existing unconditional water callback is unchanged.

The 16-byte command stays four uints: cell index, mask, add fields, set values. Mask bit 11 marks collection. AddFields bits 25–26 carry requested units; bits 27–28 hold actual removed units and bit 29 marks a valid GPU receipt. Production encoders always upload the receipt bits as zero. A collection command cannot include any other mutation, even an explicitly zero-valued RemoveAsh, SetAsh, or AddWater. Shader-side malformed exclusive requests also fail closed without a valid receipt.

`ExternalChanges` is an RWStructuredBuffer of the same 16-byte command struct. Inside its single-threaded ordered `ApplyExternalChanges` loop, collection reads current transport ash after earlier commands. If ash contamination is zero it removes `min(requested, ash)`; otherwise it removes zero. It writes the resulting amount and validity into that command. The ordinary simulation has not run yet. Earlier contamination or removal affects the amount; later changes and normal ash deposition/transport/decay cannot rewrite the receipt.

After normal simulation, delta readback, and buffer swap, the coordinator reads the appended command and validates exact cell, request, mask, other bits, receipt validity and `collected <= requested`. Native `ComputeBuffer.GetData` reads one structured `FireSimGpuChange` at the **command index**. Unity's abstract `ReadElements` also uses structured element offsets and counts, returning four uint words for one command. It never interprets the command index as a uint-word offset. Missing/malformed output or failed readback is an indeterminate failure, not a fabricated zero.

Only then does the callback run, before simulator listeners. Existing `FireSimStepInputException` outcomes apply: NotApplied before ApplyExternalChanges begins, Indeterminate after apply began through a failed callback, Committed for later observer failure after callback completion. Native integration must mint only the receipted quantity under an unsafe-save/resource-operation guard, and must never refund or replay an ambiguous conversion. A receipt is transient and immediately committed to host state; it is not a second persisted ash ledger.

Validation at the source milestone: 126 portable tests and 617 native-project tests passed. The sole controller then executed exact shader/backend revision `747eafe` using licensed Unity 6000.3.6f1 on macOS M2 Pro: all 9 focused cases (5 collection + 4 existing external-change cases) passed, followed by all 26 shader cases, with zero skips or failures. Independent capture decoding confirmed every receipt scenario and preserved nonreceipt bits across all 22 focused commands. Later changes only document the protocol and preserve optional legacy snapshot comparison; shader/backend execution is unchanged. Evidence is retained at `/tmp/wildfire-ash-receipt-gpu-747eafe/REPORT.md`. The batch runner now captures `appliedChangeWords` immediately after external apply and before simulation, and the snapshot reader preserves them. Fixtures exercise competing collections, prior contamination, prior removal plus later addition, zero/empty collection, and ash falling after collection. Native worker arrival, save/load, carried-good accounting, cancellation and final deposit require a separate integration proof.
