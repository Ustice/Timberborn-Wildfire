# Process Review

Use for a focused workflow question when requested or when a recurring problem warrants independent investigation. No routine retrospective or separate agent is required. Follow [AGENTS.md](../../AGENTS.md).

Start from observed friction: repeated failures, conflicting ownership, unnecessary approvals, duplicated evidence, or unclear instructions. Read the affected guidance and a small amount of relevant task evidence. Distinguish a durable constraint from a workaround for an old incident.

Recommend the smallest change that reduces work or prevents a concrete failure. Prefer removing obsolete rules and consolidating duplicated guidance before adding another checklist. For an uncertain change, state what improvement is expected and what observation would justify keeping or reverting it.

Edit process files only within agreed ownership, commit coherent changes, and check links and contradictions. Report the problem, remedy, verification, and any unresolved decision. If no change is useful, say so briefly; no special report schema is needed.
