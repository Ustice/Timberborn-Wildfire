# Wildfire Work Coordination

[GitHub Issues](https://github.com/Ustice/Timberborn-Wildfire/issues) holds the durable backlog. Directly authorized tasks can proceed without creating an issue first.

- [AGENTS.md](../AGENTS.md) defines shared collaboration, ownership, and safety principles.
- [Issue workflow](github-issue-workflow.md) describes issue ownership, status labels, and acceptance.
- [Assignment template](assignment-packet-template.md) helps hand off independent work.
- [Evidence template](evidence-manifest-template.md) links runtime results to artifacts.

## Optional Role Guides

Roles describe useful concerns, not a required sequence or separate agent for each function. Use only the guides relevant to the assignment.

- [Coordinator](roles/coordinator.md): concurrent work, integration, and closure.
- [Worker](roles/worker.md): implementation and focused verification.
- [QA](roles/qa.md): runtime validation and evidence quality.
- [Reviewer](roles/reviewer.md): correctness and risk assessment.
- [Tech lead](roles/tech-lead.md): architecture and integration across changes.
- [Researcher](roles/researcher.md): bounded unknowns and source-backed decisions.
- [Process reviewer](roles/process-reviewer.md): a focused workflow improvement when requested or useful.
